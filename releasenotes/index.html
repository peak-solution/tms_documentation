Release notes

Version 1.3.x​

Dashboard​

  • New widget "Activity pivot table" for grouping and counting by criteria
  • New widget "Resource pivot table" for grouping and counting by criteria

Resource scheduler​

  • Visually display and management of relations between activities

Activity manager​

  • New component list chart view
    • for visualization of activities
    • Management of relationships via drag and drop
    • Group by any criteria with unlimited criteria
  • Column chooser, Enhanced separated selection of attributes Activities grouped by
    • Activities
    • Assigned resources (unspecific)
    • Assigned resources with roles
  • Column chooser, quick filter by column name
  • Function to group resources when assigning to activities

Administration​

  • New module "Report template administration"
  • New module "Status engine administration"
  • New module "User group" administration"

Rules API​

  • Functions to create activities
  • Functions to create and delete subactivities
  • Functions to assign and unassign resources to activities
  • Functions to retrieve non-working days

Version 1.2.x​

Project calendar​

  • Display of projects in a calendar view
  • Moving tasks via drag and drop in the calendar view
  • Maintaining of relations between activities via drag and drop in the calendar view
  • customizable information table

Administration​

  • Rules engine
  • Email notifications

Version 1.1.x​

Resource scheduler​

  • Scheduling of activities with drag and drop
  • Display of activities in a timeline view
  • Working on scheduling conflicts
  • Commissioning of incoming test requests

Administration​

  • User management
  • Data pool management
  • Location management
  • User role management

Activity manager​

Resource manager​

  • Resource creation and edit
